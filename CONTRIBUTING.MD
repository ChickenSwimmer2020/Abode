<h1>Contributing Guide</h1>
<h2>Please follow these while contributing.</h2>

<h3>Referring to Adobe</h3>

* Refer to Adobe products by their full software name. (EG: "Adobe Animate software").
* Do not use Adobe Logos/Icons. Implication of Adobe's involvement in Hydro-Frame is disallowed.
* keep comparisons between Hydro-Frame and Adobe Software factual, and verifiable.
* When implementing file support, link sources and publications as to the file specifications. DO NOT USE COPIED CODE FROM ANY COMPANY/PERSON.
